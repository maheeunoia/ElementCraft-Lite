# ElementCraft

بازی جدول تناوبی با گرافیک پیکسلی (ماینکرفتی).

## اجرا
فایل `index.html` را در مرورگر باز کنید (یا در VS Code با افزونه‌ی Live Server).
برای نمایش فونت‌های پیکسلی و فارسی اینترنت لازم است؛ بدون اینترنت هم بازی با فونت پیش‌فرض کار می‌کند.

## ساختار
- `assets/js/data.js` : عناصر و ترکیب‌ها (برای ترکیب جدید یک آیتم به REACTIONS اضافه کنید)
- `assets/js/voxel.js` : رسم بلوک‌های پیکسلی
- `assets/js/game.js`  : منطق بازی
- `assets/css/style.css` : ظاهر
- `assets/background.png` : تصویر پس‌زمینه
